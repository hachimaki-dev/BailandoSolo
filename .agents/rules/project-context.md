## Architecture Gotchas

1. **Flask serves API only in dev.** In production (packaged Electron), Vue is loaded from `ui/dist/` via `file://` protocol — Flask only handles `/api/*` calls.

2. **Audio source resolution is complex.** Songs can have `song.url` (YouTube preview), `song.path` (server stream path), or `song.filename` (bare filename). The `AudioPlayer.vue` watcher handles all three cases.

3. **Mobile interface is self-contained.** `static/mobile.html` is 113KB of inline HTML/CSS/JS. It does NOT use Vue. Changes to the desktop UI do not affect mobile.

4. **Download progress uses thread-safe dict** (`server/state.py`), not a task queue. This is intentional — the app handles 1-2 concurrent downloads max.

5. **Theme system is CSS-variable-only.** Themes must NEVER write class selectors. See `THEME_GUIDE.md`.
