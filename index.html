Tu música. Tus reglas. Tu disco duro.

ARRIBA LA MÚSICA (Arranque Rápido en Local)

Selecciona tu sistema e ingresa estos comandos en tu terminal:

Bash (Linux/macOS)
PowerShell (Windows)
Terminal - bash/zsh (Linux/macOS)
# 1. Clona el repositorio oficial
user@host:~$ git clone https://github.com/hachimaki-dev/BailandoSolo.git

# 2. Entra al directorio
user@host:~$ cd BailandoSolo

# 3. Otorga permisos y arranca la App
user@host:~/BailandoSolo$ chmod +x start.sh
user@host:~/BailandoSolo$ ./start.sh

# ¡Y listoco! El script automatiza venv, dependencias y abre Electron. xDD
PowerShell (Windows)
# 1. Clona el repositorio
PS C:\> git clone https://github.com/hachimaki-dev/BailandoSolo.git

# 2. Entra al directorio
PS C:\> cd BailandoSolo

# 3. Levanta el entorno de Python y dependencias
PS C:\BailandoSolo> python -m venv venv
PS C:\BailandoSolo> .\venv\Scripts\Activate.ps1
PS C:\BailandoSolo> pip install -r requirements.txt

# 4. Instala librerías front y arranca
PS C:\BailandoSolo> pnpm install; pnpm --dir ui install; pnpm run dev

# ¡Listo para reproducir sin intermediarios! xDD
